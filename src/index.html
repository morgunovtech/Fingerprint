Fingerprint

by morgunov.tech
    3 шага защиты:
    1. Firefox: about:config → privacy.resistFingerprinting=true
    2. Chrome/Edge: «Замок» → Параметры сайта → Сбросить разрешения
    3. iOS/Android: Отключить межсайтовое отслеживание + блокировщик
    Методология (энтропия и перцентиль)
    Энтропия отпечатка: H = −∑ log₂ pᵢ(vᵢ), где pᵢ берутся из локальных частот.
    «Уникальнее, чем X%» — перцентиль CDF(H), интерполяция по квантилям.
    Редкие значения — сглаживание Лапласа. Корреляции частично учтены (GPU↔платформа, экран↔DPR).
    Политика приватности
    Всё считается локально, без сетевых запросов. Пункт «Гео по IP (/headers)» опционален и обращается только к вашему серверу. Внешних шрифтов, аналитики и трекеров нет.
