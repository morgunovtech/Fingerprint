# Перенос текущего состояния в новую ветку

Ниже пример пошагового алгоритма, который поможет перенести код, над которым вы сейчас работаете, в отдельную ветку.

1. Убедитесь, что все нужные изменения сохранены локально.
2. Посмотрите текущий статус репозитория и запомните название активной ветки:
   ```bash
   git status -sb
   ```
3. Создайте новую ветку от текущего состояния:
   ```bash
   git checkout -b <имя-ветки>
   ```
   *Например:* `git checkout -b release/2025-07-10`.
4. Проверьте, что находитесь в новой ветке:
   ```bash
   git branch --show-current
   ```
5. Зафиксируйте изменения в новой ветке (если ещё не делали этого):
   ```bash
   git add .
   git commit -m "feat: описание изменений"
   ```
6. Отправьте ветку на удалённый репозиторий:
   ```bash
   git push -u origin <имя-ветки>
   ```
7. После публикации ветки создайте Pull Request или продолжайте работу, пока изменения не будут готовы к ревью.

> Примечание: если в текущей ветке есть незакоммиченные изменения, их нужно либо закоммитить, либо отложить (`git stash`), прежде чем переключаться.
